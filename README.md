# دار بداية

عرض تفاعلي لمشروع **دار بداية** – مؤسسة المجد للتنمية، حلب.

## المحتوى
- `index.html`: العرض كاملاً في ملف واحد، والخطوط والصور مدمجة فيه، فيعمل دون إنترنت.
- `render.yaml`: إعداد النشر على Render كموقع ثابت.

## التشغيل محلياً
افتح `index.html` في أي متصفح.

## النشر على Render
1. ارفع هذا المجلد إلى مستودع على GitHub.
2. من Render اختر **New → Blueprint** واختر المستودع.
3. يقرأ Render ملف `render.yaml` تلقائياً وينشر الموقع.
